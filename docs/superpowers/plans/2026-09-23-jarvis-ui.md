# 贾维斯悬浮窗 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-09-23-jarvis-ui-design.md` 重做 `macos/` 原生悬浮窗：Metal 粒子形象、智能显隐、贴边细带、环形 HUD Hover 层、快速回复输入条、设置窗口，以及 host 端 UI 数据接口。

**Architecture:** SwiftPM 包拆成 `JarvisPanelCore`（纯逻辑库，无 AppKit，可单测）和 `JarvisPanel`（AppKit/SwiftUI/Metal 可执行目标）。Core 暴露快照模型、API 协议、状态合成、设置、ViewModel、粒子模拟、布局与显隐判定；App 只负责窗口、渲染、系统事件和视图。host 端（`src/index.ts`）扩展 `/jarvis/state` 并新增 4 个路由。

**Tech Stack:** Swift 6 / SwiftPM（swift-tools 6.0，macOS 14+）、AppKit、SwiftUI、Metal（运行时编译着色器源码）、XCTest；host 端 TypeScript（tsc）。

## Global Constraints

- 形象直径 120pt；归一化半径：核心 0–0.40、小环 0.40–0.70、大环 0.70–1.00；绘制比例 1 单位 = 55.2pt（120/2×0.92）。
- 颜色：青 `#5CE1FF`、琥珀 `#FFC24D`、红 `#FF5F5F`。
- 粒子档位：极简 300 / 精简 600 / 默认 900，界面只显示名字。
- 显隐默认：DSH 前台不透明度 100%，其他 35%（可调 15–100%），接近 80pt 渐显，醒目状态至少 85%。
- 拖动阈值 4pt，吸附距离 30pt；Hover 按钮半径 88pt、间隔 30°、最多 ±30°；读数对面需要 110pt。
- DSH bundle id 前缀 `ai.deepseek.dsh.desktop`。
- 设置文件 `~/.dsh/jarvis/panel.json`；运行时文件 `~/.dsh/jarvis/runtime.json`（可被 `JARVIS_RUNTIME_FILE` 覆盖）；演示模式 `JARVIS_DEMO=1`。
- 所有界面文案为简体中文。
- 帧率：待机 30fps、其余 60fps、隐藏 0fps。
