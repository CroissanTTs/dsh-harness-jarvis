# H1 Global Hotkey Implementation Plan

> **For agentic workers:** Execute inline against the approved backlog H1; the parent task owns final review and integration. One implementation commit, no live panel restart in this worktree.

**Goal:** Open and focus Jarvis input from any app using a configurable Carbon hotkey without accessibility permission.

**Architecture:** Core owns a validated physical key/modifier specification, transactional registration lifetime, input toggle policy, and visibility override. AppKit owns Carbon registration and a focused recorder control. Settings persist only after registration succeeds; failed changes retain the previous registration.

**Tech Stack:** Swift, Carbon RegisterEventHotKey, AppKit, SwiftUI, XCTest.

## Steps

- [x] Add `HotKeyTests.swift`: parse/format single and multiple modifiers, digits/F keys, reject missing modifiers and unknown keys; test registration replacement/conflict/cleanup and input open/focus/close decisions. Run `cd macos && swift test --filter HotKey` and observe missing implementation.
- [x] Add Core `HotKeySpec.swift` and `HotKeyBinding.swift`. Encode Carbon modifier bit values without importing AppKit, canonicalize strings as `⌃⌥⇧⌘` plus key label, and use a registration closure returning an optional cleanup closure. Failed registration returns false without changing the current spec or cleanup.
- [x] Add settings persistence and visibility tests. `PanelSettings.hotKey: String?` defaults to nil and invalid persisted strings normalize to nil. `VisibilityInput.inputOpen = true` returns visible opacity 1 before hidden checks. Run targeted tests red, implement, then run green.
- [x] Add native `HotKey.swift` with InstallEventHandler/RegisterEventHotKey and paired UnregisterEventHotKey/RemoveEventHandler. Add `HotKeyRecorder.swift` using only a local focused responder; Escape cancels, invalid combos stay in recording, successful registration persists, conflict displays `快捷键被占用`.
- [x] Wire AppController startup except snapshots, settings registration callback, and synchronous input toggle/focus. Open overrides visibility immediately; close re-evaluates existing hide policy. Release registrations on application termination.
- [x] Run plugin tests, all Swift tests, `npm run build`, `macos/build.sh`, and `git diff --check`. Update H1 backlog record only, commit all H1 files once, return evidence to parent for review/merge.
