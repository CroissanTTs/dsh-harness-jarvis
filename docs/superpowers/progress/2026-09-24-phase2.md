## 已知技术事实（设计依据）

- DSH 每个 agent 有独立的 `{provider, model, reasoningEffort}`，运行中可切，下一次请求生效，切模型会自动插入"model changed"提示（`packages/core/agent/src/model-selection.ts`）。
- 插件侧可用入口：会话控制器 `selectModel({sessionId, provider, model, reasoningEffort})`（`packages/api/session-controller/src/commands.ts:133`）。**副作用**：它会同时 `agentDefaultModel.saveSelection` 改掉全局默认模型——贾维斯调用时需规避或事后还原，设计时必须定方案。
- 审批请求 `approval/request` 只带 `agent / toolName / callId / reason?`；具体命令需从该会话挂起的工具调用中取（现有 `approvalCommand()`，`src/index.ts:964`）。
- 托管集目前只是 `~/.dsh/jarvis/managed.json` 里的 id 数组（`src/managed.ts`），无任何按会话配置。
- 规格文档 `SPEC.md` §11 已有四级权限草表；§10.1 已有审批记录 schema 草案。
